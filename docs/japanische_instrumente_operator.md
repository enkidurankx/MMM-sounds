# Japanische Perkussion: Operator-Presets

16 Instrumente als Ableton-Operator-Presets (.adv) sowie zwei Zusatzsätze.

Die fünf Metalle Atarigane, Bonsho, Chappa, Rin und Shoko gibt es in **v3.2**. Das ist die Fassung, die bei lautem Anschlag nicht mehr zerrt. Die übrigen elf Instrumente sind **v3**.

## Trommeln (Taiko und Tsuzumi)

| Preset | Instrument |
|---|---|
| O-Daiko | große Fasstrommel, tiefer Donner |
| Okedo-Daiko | Riementrommel, dumpfer und weicher |
| Shime-Daiko | kleine, straff gespannte Trommel, hell und knackig |
| Taiko Ka | Schlag auf den Holzrand der Taiko („ka“) |
| Ko-Tsuzumi | Schultertrommel aus dem Nō-Theater, mit veränderbarer Tonhöhe |
| O-Tsuzumi | Hüfttrommel, harter, trockener Schlag |
| Kakko | kleine Zweifelltrommel aus der Gagaku-Hofmusik |

## Zusatzsätze

### Atarigane Jūni-ritsu (v2)

12 Presets, eines pro Ton der Gagaku-Stimmung. Grundlage ist das Atarigane v3.2.

- Jedes Preset hat seinen Ton fest eingebaut: Transpose für den Halbton, dazu ein fester Cent-Versatz über die Pitch-Hüllkurve.
- Auf der Pad-Note C3 klingt der Satz zwischen C4 und B4, also etwa 262 bis 490 Hz.

| Preset | Taste | Abweichung vom Klavier |
|---|---|---|
| 01 C shinsen | C | ±0 c |
| 02 Cs kamimu | C♯ | −9,8 c |
| 03 D ichikotsu | D | −19,6 c |
| 04 Ds tangin | D♯ | −5,9 c |
| 05 E hyojo | E | −15,6 c |
| 06 F shosetsu | F | −2,0 c |
| 07 Fs shimomu | F♯ | −11,7 c |
| 08 G sojo | G | +2,0 c |
| 09 Gs fusho | G♯ | −7,8 c |
| 10 A oshiki | A | −17,6 c |
| 11 As rankei | A♯ | −3,9 c |
| 12 B banshiki | B | −13,7 c |

### Japanische Tonleitern (Scale-Gerät)

Presets für den MIDI-Effekt „Scale“, alle auf Grundton D (Ichikotsu):

| Preset | Töne ab D | Charakter |
|---|---|---|
| D Hirajoshi | D E F A A♯ | klassische Koto-Stimmung |
| D In-Sen | D D♯ G A C | Shakuhachi-typisch, dunkel |
| D Iwato | D D♯ G G♯ C | sehr herb, zwei Halbtonschritte |
| D Kumoi | D E F A B | weicher als Hirajoshi |
| D Miyako-bushi | D D♯ G A A♯ | „In“-Tonleiter der Stadtmusik |
| D Yo | D E G A B | helle Volksliedtonleiter, ohne Halbtöne |
